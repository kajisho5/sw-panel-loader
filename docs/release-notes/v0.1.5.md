バグチェックで見つかった点を直しました。

- 新しい画像を入れてから古い画像を消すように順番を変更（途中で失敗しても、画面の中の画像が空になって真っ暗になることがなくなります）
- 書き込み中に、接続確認が割り込んで画面と同時に通信してしまうことがあったのを防止
- JPEGを公式ソフトと同じ形式（色の間引き4:2:0）に変更。組み込み機器で読みやすい形式です
- 長いファイル名のとき、画面側の名前の日時部分が切れて前の画像を上書きすることがあったのを修正
- 画像一覧の読み取りを、続きがなければすぐ終えるように（書き込みが少し速くなります）
- 記録ファイルが1MBを超えたら作り直すように
