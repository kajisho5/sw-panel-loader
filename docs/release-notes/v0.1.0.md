最初の版です。

- 画像を選ぶ（ドラッグ可）→ 480×1920に自動で合わせて、TURZX 8.8インチ画面に書き込み
- 回転（90°ずつ）、全体表示／いっぱいに切抜き、余白の色
- 電源オンでこの画像を表示、スリープしない、明るさ
- 起動ロゴを同じ画像・黒に替える（上に帯が残る対策）
- 前に入れた画像を消す
- TFカードをFAT32で作り直す（PCのカードリーダーに挿したもの。実行時に管理者の許可を求めます）
- 「TFカード」画面の下に、うまく動かないとき用の詳しい記録

ダウンロードするもの：
- `SW PANEL LOADER_0.1.0_x64-setup.exe` … インストール版（おすすめ）
- `SW-PANEL-LOADER_0.1.0_portable.exe` … インストールせずに使う版

使う前に公式のTURZXソフトを閉じてください（同時には使えません）。
